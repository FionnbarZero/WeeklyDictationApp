## Playback and safeguards

Google generates each clip at 0.65 speaking rate. The Kore preview expresses all grade-level Mandarin profiles at 0.65 and divides requested playback rate by the recorded rate exactly once. Existing explicit 0.5 slow replay remains slower; handwriting's explicit speech-rate override is respected. Old browser-voice calibration rates (K 1.5, G2/G5 0.25) are unchanged outside this isolated flag.

Complete word/sentence recordings are used; characters are never concatenated to pronounce a word. A Dictation Streak prompt uses its four complete recorded parts in the existing owned audio lifecycle. End-of-audio still controls completion/timers. Report cancellation, navigation, late downloads, gesture activation and resource cleanup keep their shared ownership logic.

Unsupported future text and failed media retain the existing browser-speech recovery and visible retry behavior. This is not a live Google synthesis server or a guarantee that every future teacher import already has Kore audio. No credentials, new API key, IAM role or private API endpoint are embedded in the app. Supported Google ADC stays in ephemeral Cloud Shell. English Niamh installation remains separate.

## Native-media finding and repair

The first native-media matrix exposed a real inherited pace bug: the player set playbackRate before calling load(), and native load reset it to 1. Both normal and slow replay therefore played at the same rate. Apply the desired rate after load, and model that reset in FakeAudio so the existing rate assertions catch a recurrence. The first failed native traces and corrected verification are retained.

The new test driver initially counted the silent gesture primer as completed speech. It now labels actual Kore response Blobs and counts only their completed playback. Reading's initial independent trial intentionally gives no model; its test now uses the existing microphone-denial/continue-without-recording comparison flow. Kindergarten Context Gap is tested against its eligible mastered pool, since the current earlier writing week has only two choices. Lily Pads uses its own Exit game label. These are test corrections, not changes to teaching rules or vocabulary. An interrupted development matrix and all original failures remain in the evidence directory; only subsequent completed runs establish final results.
