## Data compatibility and rollback

The snapshot, retained lesson sources, launch routes, retirement markers, and Grade 2 protected workspace are additive under the existing family-owned sync boundary. Grade 2 copies its scoped state and journals atomically with readback; legacy keys remain unchanged. Malformed or oversized copies block without deleting either copy. Existing completed results are immutable. Recordings and handwriting images remain temporary and are not uploaded. This is not a reset, historical identity migration, retention cleanup, or database/security deployment.

The original scoped keys are the preserved recovery copy; no real-family backup is uploaded or included in release artifacts. Synthetic copying, failure/readback, older-reader interference, pending-journal, corrected-edition, and controlled rollback coverage is documented in [A3.2 implementation evidence](./a3-curriculum-pinning.md). Older-site practice after upgrade is not automatically merged into the protected workspace. Automatic competing unfinished-checkpoint resolution and total storage growth remain A3.3.

If containment is needed, activate the **guarded** version with the existing configuration:

```sh
npx wrangler@4.147.0 versions deploy 1f36538a-04ab-4fa1-a03e-5e11f0a48422@100 --config site/ninjadojo/wrangler.toml --yes --message 'Contain A3.2 while preserving newer saved lessons'
```

Verify its manifest, served files, and preservation screen. Newer records intentionally block the old engine; rollback is containment, not an old engine resuming newer data. An already-controlled browser must close all Dojo tabs and reopen for the waiting version to take over. Never clear browser data. Provider-only rollback to the unguarded A3.1 version is insufficient after offline-shell installation. No live rollback has been executed as part of this release.
